# EYEPAINT AR markers

Печатные маркеры для режима **Свободный | AR** (lock плоскости).

| Файл | Назначение |
|------|------------|
| `eyepaint-ar-marker-a4.png` | Лист A4: бренд + центральный маркер + 4 угла |
| `eyepaint-ar-marker-card.png` | Компактная карточка — удобно убрать после фиксации |
| `eyepaint-aruco-id0.png` | Чистый ArUco ID 0 (для тестов CV) |
| `marker.json` | Словарь / ID / размеры в мм |

## Спека

- Словарь: OpenCV `DICT_4X4_50`
- Центр: **ID 0**, сторона **90 мм** (на A4) / **70 мм** (карточка)
- Углы A4: ID **1–4**, **28 мм** (опциональный multi-marker plane)
- Печать: **100% / Actual size**, лучше матовая бумага (без глянца)

## Как пользоваться

1. Распечатать A4 или карточку.
2. Положить на стол / лист.
3. В студии: **AR** → дождаться фиксации.
4. Убрать маркер — референс остаётся на плоскости.
5. Камера сдвинулась → **Перекалибровать**.

Перегенерация: `python3 scripts/generate-ar-marker.py`
