# EYEPAINT — фичи и поведение

Веб-приложение «калька»: референс поверх камеры листа. Стек: Vite + React + TS, Tailwind v4, GitHub Pages (`base: /Eyepaint/`), P2P через Trystero MQTT.

Полная карта системы — skill `eyepaint-app`.  
Дизайн-система (токены, панели, антипаттерны, mobile/ПК) — skill `eyepaint-design`.  
Бэклог идей — `docs/IDEAS.md`.

## Экраны

| Экран | Вход | Суть |
|-------|------|------|
| **Welcome** | `/Eyepaint/` | Бренд, фото/галерея → Studio, «Телефон как камера», уроки |
| **Studio** | файл или урок | ПК-студия: сцена + рельса инструментов слева, слои справа |
| **CameraRoom** | кнопка или `?join=CODE` | Телефон стримит камеру в комнату |
| **Onboarding** | первый запуск | 3 шага, Skip / Дальше; ключ `eyepaint-onboarding-done-v1` |

## Studio — сцена

- Live-камера (локальная или remote с телефона) + референс(ы) поверх.
- Жесты активного слоя: pan / rotate / scale / tilt (хоткеи переназначаются).
- Колёсико — зум активного слоя.
- Замок позиции, отражение (per-layer), скрытие UI.
- Композит-фото: камера + референс → share/download.
- Flash shutter, крест-центр, статус камеры в шапке.

## Studio — инструменты

Вертикальная рельса слева (Photoshop-like). Клик по инструменту открывает его настройки:
- **ПК (≥960px):** настройки слева от сцены, **слои всегда справа**.
- **Телефон:** компактная нижняя панель инструмента; слои — sheet по кнопке «Слои».

| Инструмент | Панель |
|------------|--------|
| Рука | прозрачность, атмосфера, сессия, freeze/torch |
| Пипетка | ColorsPanel (+ pickMode) |
| Лупа | размер/зум (включается при выборе) |
| Проекция | ProjectPanel |
| Калька / Гиды | секции MainPanel |
| Позы | PosesPanel |
| Слои | колонка справа / sheet |

### Бывшие вкладки дока (логика та же)

### Основное / рука + калька + гиды + лупа
- Прозрачность референса (мастер).
- **Калька** — CSS-фильтр на видео (контраст/свет/сатурация), сила 0–100%.
- **Атмосфера** UI: тёмная / светлая (`data-atmosphere`, токены `--fg*` / `--glass*`).
- **Гиды**: нет / 3×3 / лицо / рост (+ прозрачность сетки).
- **Лупа**: реальный зум камеры+референса под курсором; размер 100–260px; зум 1.5–3×.
- **Сессия**: 25/45/90 мин; авто-снимок «до»; галерея прогресса (localStorage).
- **Слои** (до 3): opacity / visible; **активный** слой — цвета + transform + flip.
- Порядок стека: массив `layers` — индекс 0 сзади, последний спереди; в UI список сверху = ближе к тебе.
- Настройки → **Проект**: сохранить `.eyepaint.json`; автосейв сессии в IndexedDB (`eyepaint-sessions-v1`) + meta в localStorage; Welcome: «Продолжить сессию» / «Открыть проект».
- Тонкий кастомный scrollbar (`.eyepaint-scroll`) в доке и списке слоёв.
- Клик по слою → делает его активным (отдельное редактирование).
- DnD (ручка ≡) и меню ⋮ / ПКМ: на передний план, ближе, дальше, на задний план; aux — удалить.
- Галерея/камера: если основной занят → aux слой (со смещением, сразу активный и спереди).
- Remote freeze / torch (если телефон в эфире).
- Сброс transform активного; фиксация.

### Проекция
- Слайдеры rotateX/Y, rotation, scale активного слоя.

### Цвета
- Автопалитра с точностью 1–5, допуск, сортировка hue/dominance.
- Выбор цветов, все/инверт/сброс, пипетка по активному слою.
- Режимы: серый фон / только цвет (mask + рамка).
- Пресеты: кожа / зелень / тени / моно.
- Кисть-маска (keep/remove, AND/OR) + покрытие кадра %.
- Избранные палитры в localStorage.
- При смене точности — skeleton/старые свачи, UI не схлопывается.

### Позы
- Сохранение transform+flip+opacity (+ thumbnail, selectedColorIds) активного слоя.
- Список, применить, удалить, очистить.
- Экспорт/импорт JSON.

### Настройки (⚙)
- **Связь**: создать комнату, код, QR (`?join=`), копировать, новый код, статус.
- **Клавиши**: pan/rotate/scale/tilt remap.
- **Флаги** (`eyepaint-flags-v1`): multiLayers, brushMask, sessionGallery, lessons, lightTheme.
- **Проект**: сохранить `.eyepaint.json`; очистить автосейв.

## Комната (телефон ↔ ПК)

- ПК host создаёт код; телефон guest вводит код или QR/deep-link.
- Data-channel команды: `ping`, `freeze`, `torch`, `exposure`, `focus`.
- На телефоне: freeze кадра, torch, exposure, tap-focus, батарея &lt;15%, штатив-UX.
- Честный бейдж качества: с камеры vs в эфир (не обещать фейковый 4K).

## Уроки

`public/lessons/*` + `src/lib/lessons.ts`: портрет 3/4, фигура, натюрморт — стартовый гид/opacity/калька.

## PWA / UX

- `manifest.webmanifest`, standalone.
- Toast-статусы.
- Фичефлаги и атмосфера в localStorage.

## Типичные flows (для тестов и UX)

1. Welcome → урок → Studio (гид включён) → инструмент Гиды / Рука.
2. Welcome → файл → Studio → слои → второй файл → выбрать aux → двигать только его.
3. Цвета (Пипетка): точность → пресет → mask → покрытие %.
4. Поза: сохранить → сбросить → применить.
5. ⚙ Связь → создать комнату → QR/код; на другом устройстве CameraRoom / `?join=`.
6. Лупа вкл → размер/зум → водить по сцене.
7. Атмосфера light/dark без дёрганья подписей.
8. Онбординг: пропуск сохраняет done.

## Ограничения / честность

- Фаза 5 (AR/ML/учитель) — spikes, не в продукте.
- WebRTC bitrate часто &lt; capture max; UI должен это показывать.
- Torch/exposure/focus — best-effort по capabilities браузера.
- Без бэкенда: только P2P + localStorage.
