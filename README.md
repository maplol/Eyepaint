# EYEPAINT

Приложение в духе Painter’s Eye: загружаешь референс, наводишь камеру на лист, выставляешь прозрачность и рисуешь поверх — как через кальку.

## Как пользоваться

1. Открой приложение на телефоне (удобнее всего).
2. **Сфотографируй** референс или возьми **из галереи**.
3. Разреши доступ к камере — лучше задней.
4. Подгони картинку: перетаскивание, щипок (масштаб/поворот), ползунок прозрачности.
5. Кнопка затвора снимает кадр с камеры как новый референс.
6. **Скрыть UI** убирает панели; прозрачная кнопка в правом нижнем углу возвращает их.

## Запуск

```bash
npm install
npm run dev
```

Камера работает только в безопасном контексте: `localhost` или HTTPS.

## Сборка

```bash
npm run build
npm run preview
```
