# EYEPAINT

Приложение в духе Painter’s Eye: загружаешь референс, наводишь камеру на лист, выставляешь прозрачность и рисуешь поверх — как через кальку.

## Как пользоваться

1. Открой приложение на телефоне или ПК.
2. **Сфотографируй** референс или возьми **из галереи**.
3. Подгони картинку жестами / вкладкой **Проекция** (наклоны под угол листа).
4. Таб **Цвета**: кружки палитры, серый фон / «Только цвет».
5. Таб **Позы**: сохрани несколько позиций со всеми параметрами.
6. Таб **Связь**: код комнаты на ПК → на телефоне «Телефон как камера» → тот же код.
7. **Скрыть UI** — прозрачная кнопка в углу возвращает панели.

## Запуск

```bash
npm install
npm run dev
```

Камера работает только в безопасном контексте: `localhost` или HTTPS.

## Сборка

```bash
npm run build
npm run preview
```
